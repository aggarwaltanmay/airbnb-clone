# Project Guidance

## Goal

Maintain a desktop-faithful recreation of the supplied Airbnb listing reference across the listing page, photo tour, and lightbox.

## Working rules

- Treat the assignment PDF as requirements and user messages as the source of requested changes.
- Observe the reference visually and behaviorally; do not copy its source code.
- Keep application assets local and record their provenance in `asset-sources.json`.
- Preserve controls that are intentionally inert when the reference is inert.
- Use the local Airbnb Cereal font and the existing icon treatment.
- Check the relevant reference state at the same viewport before changing layout values.
- Run `npm run check` and `npm run build` after implementation changes.
- Verify visible changes in the browser, including the console and key interactions.

## Project skill

Use `.agents/skills/reference-fidelity/SKILL.md` for focused visual and interaction parity work.
